# masswiki-mcp

- **Kind:** MCP server
- **Owner:** West Coast Metabolomics Center, Gert Wohlgemuth
- **Status:** public release planned
- **Source:** not yet public

## What it does

Lets an AI agent search the MassWiki mass spectrometry database: compounds, spectra, extracted ion chromatograms (EICs) and spectral similarity, and export results in standard formats.

## Tools or commands

13 tools covering compound and spectrum lookup, EICs, similarity search, and export to MSP, MGF, CSV and JSON.

## Access

- **Writes:** none (read-only).
- **Sign-in:** lab login (in progress).
- **How to get access:** contact the West Coast Metabolomics Center.

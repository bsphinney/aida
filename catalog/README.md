# AIDA tool catalog

AI tools and helpers that Genome Center labs share: MCP servers, agent skills, and gateways for local models. Point your AI agent at this folder to find a tool, and add your own with a pull request.

Each tool has one file, named after the tool, copied from [`TEMPLATE.md`](TEMPLATE.md).

## Rules for listed tools

- **Read-only by default.** A tool that can change, delete or submit anything says so in its `Writes` field.
- **No secrets or internal hostnames** in this public repository. Describe how to get access; don't paste credentials or addresses.
- **Access stays with the owner.** Each lab decides who can use its servers and gateways.
- **Say how it was checked.** Every entry needs a short verification note before it is listed.

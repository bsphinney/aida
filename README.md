# AIDA: AI for Data Analysis and Automation

A proposed UC Davis Genome Center Focus Group on practical ways to use AI coding agents to speed up omics data analysis and lab automation.

This repository holds the **final proposal**: [`proposal.md`](proposal.md), and the 2-page PDF made from it, [`AIDA_proposal.pdf`](AIDA_proposal.pdf). It also holds [`catalog/`](catalog/), a list of AI tools that Genome Center labs share. If the group is funded, the repository becomes its shared library of session write-ups and reusable agent workflows.

## How to suggest changes

Anyone with access can edit. Use whichever way suits you:

- **In the browser:** open [`proposal.md`](proposal.md), click the pencil icon, make your change and choose "Create a new branch and start a pull request".
- **With your AI agent** (Claude Code, Codex, Gemini CLI or another): clone the repository and ask your agent to make the change. Agents read [`AGENTS.md`](AGENTS.md) and [`CLAUDE.md`](CLAUDE.md), which hold the proposal's requirements.
- **Just comments:** open an issue, or comment on a pull request.

Things to keep in mind:

- The final proposal must fit on **2 pages** as a PDF, so cut as much as you add.
- Placeholders in `[square brackets]` and lines starting "Open question" still need answers.
- **This repository is public.** Don't add anyone's name as a participant without their agreement, and don't include unpublished data or anything confidential.
